How to read the map and colors

The system map shows each module once. A filled dot on a routed wire is a real branch; a gap means one wire passes underneath another without connecting. Moving dashes show direction, not live traffic. Block colors describe PaperAtlas code, not an external provider: Focused means one clear job; Review marks a seam to improve; Hotspot means responsibilities change together; Scaffold sits outside the live loop. A block takes its highest component priority. These judgments do not imply AI authorship.

Trace one request: start a project scan

The console posts to /api/lab/projects/{id}/triage. The gateway forwards to lab-api; the shared service creates a triage and queues triage.run. A worker discovers, distills and matches. The console reads progress as server-sent events. The result is a shortlist, not an automatic build.
