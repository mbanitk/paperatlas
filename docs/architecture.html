How to read the map and colors

Dashed outlines mark ownership boundaries, not network hops. Arrows show representative calls and payload transfers, not every dependency. The gateway forks to two HTTP services. Each block color describes PaperAtlas code, not an external provider. Focused means one clear job; Review marks a specific seam to improve; Hotspot means several responsibilities change together; Scaffold sits outside the live loop. A block takes its highest component priority. These judgments do not imply AI authorship.

Trace one request: start a project scan

The console posts to /api/lab/projects/{id}/triage. The gateway forwards to lab-api; the shared service creates a triage and queues triage.run. A worker discovers, distills and matches. The console reads progress as server-sent events. The result is a shortlist, not an automatic build.
