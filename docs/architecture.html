Level 01 / System map

Trace one request: start a project scan

The console posts to /api/lab/projects/{id}/triage. The gateway forwards to lab-api; the shared service creates a triage and queues triage.run. A worker discovers, distills and matches. The console reads progress as server-sent events. The result is a shortlist, not an automatic build.
